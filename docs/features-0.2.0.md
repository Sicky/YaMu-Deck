# Моя волна и качество звука — 0.2.0

«Моя волна» запускается с главного экрана или отдельной кнопкой слева. Используется персональная станция `user:onyourwave` Яндекса. События запуска станции, начала трека, пропуска и завершения передаются API с batch ID. Следующие партии загружаются автоматически; недоступные треки и недавние дубликаты отфильтровываются. Выбор обычного трека отключает волну; переход между экранами её не останавливает. При сбое загрузки следующей партии можно повторить кнопкой следующего трека. Перемешивание относится к обычной очереди; порядок волны задаёт сервис Яндекса.

Качество выбирается в настройках или через кнопку формата в плеере:

- Обычное — MP3 до 192 кбит/с, при наличии такого варианта.
- Высокое — лучший доступный MP3, до 320 кбит/с.
- Превосходное / Lossless — FLAC без потерь, если его разрешает API для трека и аккаунта.

Настройка сохраняется между запусками и применяется со следующего трека, не прерывая текущий. Кнопка в плеере показывает фактический формат/битрейт; при недоступном FLAC показывается уведомление и используется MP3. Если API возвращает только зашифрованный transport encraw, используется MP3: зашифрованные байты не отправляются аудиоплееру. FLAC запрашивается с transport raw. Прокси сторонних сервисов нет, доступ к токену по-прежнему только у основного процесса при Device Flow.

Реализация сверена с открытыми источниками:

- [Методы радио](https://github.com/MarshalX/yandex-music-api/blob/main/yandex_music/_client_async/radio.py)
- [Подпись запроса качества](https://github.com/MarshalX/yandex-music-api/blob/main/yandex_music/utils/sign_request.py)
- [Поля формата аудио](https://github.com/MarshalX/yandex-music-api/blob/main/yandex_music/track/file_download_info.py)

Проверки: 20 тестов API и две проверки Electron — интерфейс настроек/очереди/авторизации и сценарий волны с имитацией API и аудио (пропуск, завершение, пополнение, выход из режима волны). Тесты не используют реальный аккаунт. Качество реального звука, доступность подписки, воспроизведение FLAC и персональные рекомендации требуют проверки с пользовательским аккаунтом на Windows/Steam Deck. Точное совпадение набора рекомендаций с веб-клиентом не гарантируется неофициальным API. Настройки настроения волны, как в веб-клиенте, в этой версии не реализованы.
