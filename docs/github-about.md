Неофициальный клиент Яндекс Музыки для Steam Deck и Windows: Моя волна, управление геймпадом, MP3/FLAC и системные медиакоманды MPRIS.

Unofficial Yandex Music desktop client for Steam Deck and Windows, with My Wave, gamepad controls, MP3/FLAC playback and MPRIS media controls.
